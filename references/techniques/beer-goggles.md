# Beer Goggles

## When to use
Use when the problem seems ugly, stale, or dead on arrival.

## Method
1. Pick the least sexy part of the challenge.
2. Pretend it is the most valuable part.
3. Ask what would make that part magical.

## Example
Problem: "Nobody reads the docs."

Beer Goggles answer: "What if the docs are a puzzle, not a manual?"

## Why it works
The hidden value often sits in the boring part nobody is looking at.
