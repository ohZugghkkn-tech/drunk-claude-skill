# Hold My Beer

## When to use
Use when a normal idea exists and you want to escalate it into a bizarre but valuable version.

## Method
1. Start with the sane version.
2. Ask what the ridiculous version would look like.
3. Push one step beyond comfort.
4. Keep the absurd version only if it reveals a real insight.

## Example
Normal: "Let's ship a member dashboard."

Hold My Beer: "What if the dashboard is not a dashboard at all, but a miniature life system that adapts to the user's mood and habits?"

## Why it works
Extremes reveal the middle path you wouldn't have discovered from a safe starting point.
