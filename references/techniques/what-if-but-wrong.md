# What If But Wrong

## When to use
Use when assumptions are too strong to question directly.

## Method
1. Pick a normal assumption.
2. Add a deliberately dumb twist.
3. Take the twist seriously for 60 seconds.
4. See where it leads.

## Example
Normal assumption: "Software should be reliable."

Wrong version: "What if software was designed to fail in visible, recoverable ways?"

## Why it works
The dumb version bypasses the brain's reality filter and reveals deeper structural truths.
