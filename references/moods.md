# Drunk Mood Matrix

Each mood changes the flavor of the output while keeping the same underlying creative engine.

## Best fit by problem type

| Problem type | Best mood | Why |
|---|---|---|
| Vision, strategy, long-term signals | `philosophical` | Finds meaning and larger patterns |
| Brainstorming, ideation, idea storms | `chaotic` | Most connection-heavy and unpredictable |
| Critique, reframe, pivot | `melancholy` | Finds beauty in the broken version |
| Disruption, status quo challenges | `aggressive` | Direct, confrontational, bold |
| Design, UX, branding, emotional hooks | `flirty` | Seductive, charming, alluring |

## Mixing moods

Use one mood per session or invocation. Across a longer conversation, switching moods creates the effect of a creative rollercoaster.
